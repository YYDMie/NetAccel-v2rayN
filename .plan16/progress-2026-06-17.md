## 已完成

### WP-05 - Managed runtime connection

- 实现 `ConnectionOwnershipCoordinator`，覆盖 Managed/Classic owner 互斥、
  并发 acquire、stale snapshot 恢复和 cross-process mutex 基础能力。
- 实现 `ManagedConnectionCoordinator`，覆盖托管启动、停止、授权集合内自动/手动选线、
  安全切线、失败恢复和自动 fallback。
- 接入 ServiceLib runtime config override，托管连接不读取经典 SQLite 活动节点、
  DNS、路由或端口策略。
- 增加 TUN 清理公共封装 `AppManager.RemoveTunDeviceAsync()`，避免 Managed 层直接引用
  internal `WindowsUtils`。
- Windows E2E 已尝试但 blocked：缺管理员权限、真实 Master 分配线路和 R3 managed shell。

### WP-06A - Managed source isolation guards

- 新增 `ManagedProfileGuard`，以 `managed:` IndexId 前缀识别托管 ProfileItem。
- ServiceLib handler 层阻断托管 edit/delete/copy/share/export 相关路径。
- ViewModel 层增加用户友好阻断。
- 经典本地节点、通用订阅、导入导出保持兼容路径可用。

### WP-06B - Backup isolation, classic launcher, owner guard, exit cleanup

- 新增 `ManagedConnectionGuard`，作为 ServiceLib 到 NetAccel.Managed 的静态桥接。
- 新增 `ClassicModeLauncher`，Managed -> Classic 前安全停止托管连接，并持有 Classic
  owner lease，阻止 Managed 再次并发 acquire。
- 新增 `ManagedExitCleanup`，统一退出清理、post-restore 清理和 backup exclusion helper。
- `AppManager.AppExitAsync` 接入 managed cleanup。
- `MainWindowViewModel.Reload`、`StatusBarViewModel.SetListenerType`、`DoEnableTun`
  接入 owner guard。
- `BackupAndRestoreViewModel` 排除 `managed-*` / `netaccel-credential-*` 文件，
  restore 后清理 SQLite 中 `managed:*` ProfileItem/SubItem。

### WP-06 overall acceptance
