## 任务 1：安装并启动

### 前提条件

- Windows 10 或 Windows 11 操作系统
- 已获取 NetAccel 安装包（`.exe` 安装程序）
- 拥有管理员账户或具备安装权限

### 操作步骤

1. 双击下载的安装程序文件。
2. 如系统弹出"用户账户控制"提示，点击"是"允许安装。
3. 等待安装完成。
4. 安装完成后，NetAccel 自动启动。
5. 屏幕显示 NetAccel 登录界面。

### 预期结果

- 安装过程无报错。
- 安装完成后桌面上出现 NetAccel 图标。
- 应用自动启动并显示登录页面。
- 登录页面包含账号输入框、密码输入框和登录按钮。

### 验证方法

- 确认桌面上存在 NetAccel 图标。
- 双击图标可再次启动应用并看到登录界面。

| 安装后未自动启动 | 系统阻止自启动 | 手动双击桌面 NetAccel 图标 |

## 任务 2：登录账号

### 前提条件

- 已完成任务 1，NetAccel 已启动并显示登录界面。
- 拥有管理员分配的账号和密码。
- 设备已连接互联网。

### 操作步骤

1. 在登录界面的"账号"输入框中输入账号。
2. 在"密码"输入框中输入密码。
3. 点击"登录"按钮。
4. 等待系统处理（界面显示加载状态）。
5. 登录成功后，应用自动进入首页。

### 预期结果

- 登录按钮点击后进入加载状态，按钮暂时不可重复点击。
- 登录成功后页面切换至首页。
- 首页显示当前加速状态（默认为"未连接"）和推荐线路名称。
- 设备已绑定到该账号，配置已拉取并缓存。

### 验证方法

- 确认首页显示"未连接"状态和推荐线路信息。
- 确认页面底部导航栏可见（首页、线路、诊断、记录、设置）。

### 常见问题与恢复

| 问题 | 可能原因 | 恢复方法 |
|------|----------|----------|
| 提示"账号或密码错误" | 输入有误或账号未分配 | 重新检查输入；联系管理员确认账号状态 |
| 提示"网络连接失败" | 设备无互联网或服务器不可达 | 检查网络连接后重试 |
| 提示"设备未授权" | 管理员未将该设备加入允许列表 | 联系管理员添加设备 |
| 提示"账号已被禁用" | 管理员已禁用该账号 | 联系管理员启用账号 |
| 长时间加载无结果 | 服务端配置同步延迟 | 等待 30 秒后重试；若反复出现，联系管理员 |

## 任务 3：一键加速

### 前提条件

- 已完成任务 2，已登录并处于首页。
- 当前状态为"未连接"。
- 首页显示推荐线路或已分配线路。

### 操作步骤

1. 在首页找到加速按钮（通常位于页面中心或显眼位置）。
2. 点击加速按钮。
3. 等待连接建立（按钮状态变化，显示"连接中"）。
4. 连接成功后，首页状态变为"已连接"。

### 预期结果

- 点击加速按钮后，按钮状态变为"连接中"，显示加载动画。
- 连接建立后，首页显示"已连接"状态。
- 显示当前使用的线路名称。
- 系统代理已自动激活，浏览器流量通过加速线路转发。
- 记录页自动记录一条"已连接"事件。

### 验证方法

- 确认首页状态显示"已连接"。
- 确认加速按钮变为"断开"样式（可点击断开连接）。
- 打开浏览器访问网站，确认可以正常上网。
- 切换到记录页，确认有连接事件记录。

### 常见问题与恢复

| 问题 | 可能原因 | 恢复方法 |
|------|----------|----------|
| 按钮点击无反应 | 连接状态异常 | 等待几秒后重试；若仍无反应，重启应用 |
| 显示"连接失败" | 当前线路不可用 | 系统会自动尝试备用线路；若反复失败，手动切换线路 |
| 显示"权限不足" | 未获得加速权限 | 联系管理员确认权限配置 |
| 显示"引擎异常" | 本地加速引擎未启动 | 尝试点击诊断页的"一键修复"；若无效，重启应用 |
| 已连接但无法上网 | 系统代理设置冲突 | 进入诊断页面检查；或断开后重新连接 |

## 任务 4：切换线路

### 前提条件

- 已完成任务 2，已登录。
- 账号已分配至少两条可用线路。
- 当前可以已连接或未连接状态。

### 操作步骤

1. 点击底部导航栏中的"线路"标签，进入线路页面。
2. 浏览可用线路列表。每条线路显示名称和状态标签（如"可用"、"维护中"）。
3. 找到一条状态为"可用"的线路，点击选中。
4. 确认选择（如有确认提示）。

### 预期结果（已连接状态下切换）

- 点击新线路后，应用开始切换。
- 连接状态短暂显示"切换中"。
- 切换完成后，连接恢复为"已连接"状态。
- 首页显示更新后的线路名称。
- 不需要先手动断开再重新连接，切换过程自动完成。

### 预期结果（未连接状态下切换）

- 线路选择立即生效。
- 首页推荐线路更新为新选择的线路。
- 下次点击加速按钮时，将使用新选择的线路。

### 验证方法

- 确认线路页面中被选中的线路有高亮或选中标记。
- 返回首页，确认显示的线路名称与选择一致。
- 若处于已连接状态，确认切换过程中浏览器上网未长时间中断。

| 问题 | 可能原因 | 恢复方法 |
|------|----------|----------|
| 线路显示为灰色不可选 | 线路处于维护中或不可用 | 选择其他可用线路 |
| 切换后连接失败 | 目标线路临时不可用 | 系统自动回退到之前的线路；或手动选择其他线路 |

| 提示"配置不同步" | 本地配置与服务端不一致 | 进入诊断页面点击"一键修复"重新同步 |

## 任务 5：查看诊断

### 前提条件

- 已完成任务 2，已登录。
- 应用已启动（无论是否已连接）。

### 操作步骤

1. 点击底部导航栏中的"诊断"标签，进入诊断页面。
2. 诊断页面自动显示四项检查结果：
   - 服务连接状态
   - 当前线路状态
   - 本地网络状态
   - 加速引擎状态
3. 每项检查显示"正常"（绿色）或"异常"（红色/橙色）。
4. 若存在异常，页面底部显示"一键修复"按钮。
5. 点击"一键修复"，等待修复完成。
6. 可点击"重新检查"按钮刷新检查结果。

### 预期结果

- 四项检查全部正常时，每项显示绿色"正常"标签。
- 无异常时，"一键修复"按钮不显示或为禁用状态。
- 若某项异常，显示橙色或红色标签，并附带简短说明。
- 点击"一键修复"后，系统按顺序执行：
  1. 停止当前连接（如有）
  2. 停止残留加速进程
  3. 恢复系统代理设置
  4. 清理残留 TUN 状态
  5. 重新同步配置
- 修复完成后自动重新检查，各项恢复绿色"正常"。
- 每项检查可展开查看详细信息（展开后显示更多诊断数据）。

### 验证方法

- 确认四项检查均显示结果，无空白项。
- 确认正常状态下无红色或橙色异常标记。
- 若手动触发异常（如断开网络后检查），确认能正确检测并报告。

| 引擎异常 | 加速引擎文件损坏或被安全软件拦截 | 使用"一键修复"；若修复失败，重新安装应用 |
| 修复后仍有异常 | 问题无法自动修复 | 导出诊断包（页面下方"导出诊断包"按钮），将文件发送给管理员分析 |
| 导出诊断包失败 | 文件写入权限不足或磁盘空间不足 | 检查磁盘空间；尝试选择其他保存位置 |

## 任务 6：退出和恢复

### 前提条件

- NetAccel 正在运行。
- 当前可能处于已连接或未连接状态。

### 操作步骤

#### 6a. 关闭窗口（最小化到托盘）

1. 点击窗口右上角的关闭按钮（X）。
2. 应用窗口消失。
3. 系统托盘（任务栏右下角）出现 NetAccel 图标。

#### 6b. 从托盘恢复窗口

1. 双击系统托盘中的 NetAccel 图标。
2. 应用窗口重新显示。

#### 6c. 从托盘菜单查看状态

1. 右键点击系统托盘中的 NetAccel 图标。
2. 弹出菜单显示当前连接状态。
3. 菜单中包含快捷操作（如"断开连接"、"打开主窗口"、"退出"）。

#### 6d. 完全退出应用

1. 右键点击系统托盘中的 NetAccel 图标。
2. 在弹出菜单中点击"退出"。
3. 应用完全关闭。
4. 系统托盘图标消失。

### 预期结果

- 关闭窗口时，应用不退出，仅最小化到系统托盘。
- 若当前已连接，连接保持活跃，加速继续生效。
- 托盘图标正常显示，鼠标悬停可看到连接状态提示。
- 右键托盘菜单内容随连接状态变化：
  - 已连接时：显示"已连接 - [线路名称]"、"断开连接"选项
  - 未连接时：显示"未连接"、"快速连接"选项
- 完全退出时：
  - 若已连接，连接自动断开。
  - 系统代理设置恢复为应用启动前的状态。
  - 加速引擎进程完全停止。
  - 托盘图标消失。
  - 应用进程从任务管理器中消失。

### 验证方法

- 关闭窗口后确认任务管理器中仍有 NetAccel 进程。
- 确认托盘图标可见。
- 双击托盘图标确认窗口可恢复。
- 完全退出后确认任务管理器中无 NetAccel 进程。
- 若退出前已连接，确认系统代理已恢复（可在系统设置的网络代理中查看）。
- 确认无残留的加速引擎进程。

| Windows 关机时应用未自动退出 | 会话结束处理异常 | 通常系统会自动清理；若反复出现，手动退出后再关机 |

## 系统代理恢复说明

NetAccel 在连接时会自动设置系统代理，在断开或退出时恢复原始设置。以下情况需要关注：

- **正常退出**：系统代理自动恢复为应用启动前的状态。
- **应用崩溃**：系统代理可能未恢复。此时需手动进入"设置 > 网络和 Internet > 代理"检查并关闭代理设置。
- **已有用户代理**：若在启动 NetAccel 前已有手动设置的代理（如公司代理或 PAC 地址），退出时会恢复为该设置，不会丢失。
