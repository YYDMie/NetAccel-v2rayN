## 实机任务

### 1. 启动与登录

1. 启动 NetAccel，确认首先看到托管登录页。
2. 不使用鼠标，按 Tab 依次经过账号、密码、登录、取消，并能循环返回账号。
3. 输入管理员分配的测试账号和密码，点击“登录”。
4. 确认进入首页，只显示该账号被授权的线路信息。

**通过标准：** 登录过程有加载和错误反馈；成功后进入首页；不得看到公共线路池、套餐、订阅或线路参数编辑入口。

### 2. 一键连接并判断状态

1. 在首页确认当前为“未连接”，并能看到推荐线路或无可用线路的明确提示。
2. 点击主连接按钮，观察“连接中”到“已连接”的状态变化。
3. 确认首页显示当前线路名称，普通网页访问正常。
4. 再次点击主按钮停止连接，确认返回“未连接”。

**通过标准：** 状态不会停在含糊的加载态；失败时给出可执行说明；停止后网络正常。

### 3. 切换授权线路

1. 进入“线路”页，确认只显示管理员分配给当前账号的集合。
2. 在未连接状态选择另一条可用线路，返回首页确认名称更新。
3. 连接后再次切换到第二条授权线路，记录切换耗时和网页中断情况。

**通过标准：** 未授权线路不可见；不得编辑、分享或导出托管线路；连接中切线成功或安全回退到原线路。

### 4. 诊断与恢复

1. 进入“诊断”页，检查服务、线路、本地网络和引擎结果均有文字说明。
2. 断开网络或停止测试引擎，确认对应异常可被识别。
3. 执行“一键修复”，随后重新检查。
4. 导出诊断包，确认只包含允许清单内容，不含 token、线路参数或凭据。

**通过标准：** 修复步骤可逆；无修复条件时不会伪报成功；诊断包满足隐私边界。

### 5. 托盘与退出恢复

1. 关闭主窗口，确认应用隐藏到唯一的 NetAccel 托盘图标。
2. 双击托盘图标恢复窗口，右键菜单能显示当前状态。
3. 在已连接状态选择“退出”。
4. 用 Windows 代理设置和任务管理器确认系统代理/TUN 已恢复、引擎和客户端进程均退出。

**通过标准：** 关闭窗口不会误断开；完全退出会恢复系统状态；没有残留进程或失效代理。
